开启远程访问

远程访问使用 Tailscale 建立加密私有网络，不需要把机械臂控制台直接暴露到互联网。

控制中心和远程访问设备必须登录同一个 Tailscale 网络。

1. 安装 Tailscale

curl -fsSL https://tailscale.com/install.sh -o /tmp/install-tailscale.sh
less /tmp/install-tailscale.sh
sudo sh /tmp/install-tailscale.sh

2. 登录并开机启动

sudo systemctl enable --now tailscaled
sudo tailscale up

执行后终端会显示登录链接，请在浏览器完成授权。

3. 验证远程 IP

tailscale ip -4

4. 回到控制中心

重新点击“开启远程访问”。成功后会显示类似 http://100.x.x.x:8088 的地址。

不要关闭登录验证，也不要直接将 8080/8088 端口映射到公网。远程设备同样需要安装并登录 Tailscale。
