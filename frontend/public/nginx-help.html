开启局域网访问

后台不能代替你输入系统 sudo 密码，因此首次配置需在本机终端执行一次。

配置文件已生成在项目的 data/workstation-monitor-nginx.conf。

1. 安装 Nginx（已安装可跳过）

sudo apt-get update
sudo apt-get install -y nginx

2. 安装项目配置并启动

cd /home/zhangxin/桌面/Reily/workstation-monitor
sudo install -m 0644 data/workstation-monitor-nginx.conf /etc/nginx/conf.d/workstation-monitor.conf
sudo nginx -t
sudo systemctl enable --now nginx
sudo systemctl reload nginx

3. 验证

curl -I http://127.0.0.1:8088
curl -I http://127.0.0.1:8081

完成后回到控制中心，再点击“开启局域网访问”。控制中心使用 8088，数据采集代理使用 8081。
